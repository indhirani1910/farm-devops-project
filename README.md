# Cloud Based Farm Management System

This is a simple Cloud Based Farm Management System developed as an internship project.  
The project is built using HTML, CSS, JavaScript for frontend and Node.js with Express for backend routing.

## 🌍 Live Demo

Render Deployment Link:  
[Click here to view live website](https://farm-devops-project.onrender.com)

## 📌 Features

- User Login System  
- User Registration  
- Dashboard (Home Page)  
- Farmers Management Page  
- Crops Management Page  
- Navigation Bar  
- Logout Functionality  

## 🛠️ Technologies Used

- HTML  
- CSS  
- JavaScript  
- Node.js  
- Express.js  
- GitHub  
- Render (for Deployment)

## 🚀 How to Run the Project

1. Clone the repository  
2. Open terminal in project folder  
3. Run `npm install`  
4. Run `node server.js`  
5. Open browser and go to: `http://localhost:3000`
